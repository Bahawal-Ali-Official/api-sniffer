# API Sniffer - Endpoint Detector

API Sniffer is a browser-based API testing and security toolkit for developers and pentesters to capture, inspect, and automate network requests directly inside Google Chrome.

Official Website: https://sniffer.bahawal.top/
Chrome Web Store: https://chromewebstore.google.com/detail/api-sniffer-endpoint-dete/npgapjgfmmkkaefnbidihgheohllmjih
SourceForge: https://sourceforge.net/projects/api-sniffer/

## Features

* Target Canvas: Visually organize and track target endpoints and testing workflows.
* ASOS: A modified Kali Linux environment running in the background, accessible directly from Chrome, the extension, and DevTools.
* Free Cloud Shell: Built-in terminal access to run security scripts and tools inside the browser.
* Traffic Capture: Monitor and log HTTP, WebSocket, and WebRTC traffic in real time.
* Live Traffic Interceptor: Pause, inspect, and modify requests and responses on the fly.
* Request Repeater: Manually modify and resend captured network requests.
* Request Automator: Automate request sequences, fuzzing, and parameter testing.
* F12 DevTools Integration: Native panel inside Chrome Developer Tools for seamless debugging and testing.
* Secrets Scanner: Detect exposed API keys, tokens, and credentials in network responses and scripts.
* JavaScript Analyzer: Extract hidden API endpoints and routes from loaded JS files.
* JWT Decoder and Editor: Decode, inspect, and modify JSON Web Tokens.
* CORS Misconfiguration Scanner: Test endpoints for insecure CORS policies.
* BOLA/IDOR Comparison Tool: Compare responses across different sessions to find authorization flaws.
* Out-of-Band (OOB) Interaction Catcher: Catch blind SSRF, XSS, and XXE callbacks.
* GraphQL Schema Analyzer: Introspect and test GraphQL schemas and queries.
* Request Smuggling Detector: Check endpoints for HTTP request smuggling vulnerabilities.
* Mail Boxes: Built-in temporary email inboxes for testing sign-ups and authentication flows.
* Team Collaboration and Chat: Share requests, notes, and findings with team members in real time.

## Installation

1. Open the Chrome Web Store link: https://chromewebstore.google.com/detail/api-sniffer-endpoint-dete/npgapjgfmmkkaefnbidihgheohllmjih
2. Click "Add to Chrome" to install the extension.
3. Open the extension from the toolbar or press F12 to use it inside Chrome DevTools.
